# FrameKit

Discord Webhook Builder — Design, send, and automate Discord messages.

## ✨ Features
- Visual Discord message editor
- Components V2 support
- Live preview & JSON mode
- Webhook management
- No sign-up required
- Beautiful UI with Shadcn

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Visit `http://localhost:5173`

## 🛠️ Tech Stack
- React 19 + TypeScript
- Shadcn UI
- TailwindCSS
- Vite
- Discord.js

## 📦 Deployment
- Lovable (native)
- Vercel
- Netlify
- Docker
